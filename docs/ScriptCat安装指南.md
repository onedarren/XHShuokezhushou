## 1. 什么是脚本猫

[ScriptCat（脚本猫）](https://scriptcat.org) 是一款国产浏览器用户脚本管理器扩展，
功能定位与油猴（Tampermonkey）类似，主要特点：

- **中文界面**，对新手友好
- **完全开源免费**，代码托管在 GitHub，无闭源担忧
- 内置**脚本猫脚本站**，可以一键安装、自动更新脚本
- 支持 `GM_setValue`、`GM_xmlhttpRequest`、`GM_notification` 等本脚本用到的全部 API
- 支持 Chrome / Edge / Firefox 等主流浏览器

本脚本对脚本猫做了完整兼容，推荐国内用户优先使用脚本猫。

## 2. 安装脚本猫扩展

### 第一步：选择安装渠道（三选一）

| 渠道 | 地址 | 适用浏览器 |
| --- | --- | --- |
| Chrome 应用商店 | <https://chromewebstore.google.com/detail/scriptcat/ndcooeabhibbnggbjckcbkhghagnkcpb> | Chrome / Edge（可装 Chrome 商店扩展） |
| Edge 加载项商店 | 在 Edge 加载项中搜索「ScriptCat」 | Edge |
| GitHub Releases | <https://github.com/scriptscat/scriptcat/releases> | 任意 Chromium / Firefox，下载 crx 或 zip 离线安装 |

### 第二步：确认安装成功

1. 浏览器右上角出现**猫爪图标**（脚本猫图标）
2. 点击图标能看到「已安装脚本」面板，即安装成功
3. 如果图标未显示，点击浏览器地址栏右侧的「拼图」按钮，把脚本猫**固定**到工具栏

> 💡 安装了多个脚本管理器（例如同时装了油猴和脚本猫）可能导致冲突，建议只保留一个并启用。

## 3. 安装小红书AI自动获客助手脚本

### 方式 A：GitHub 直装（推荐）

1. 用浏览器打开下面的链接：
   <https://github.com/onedarren/XHShuokezhushou/raw/main/dist/小红书AI自动获客助手-obfuscated.user.js>
2. 脚本猫会自动检测到用户脚本，弹出**安装确认页**
3. 确认页会展示脚本的名称、版本、权限（@grant）和匹配域名（@match），核对无误后点击「安装」
4. 出现「安装成功」提示即完成

### 方式 B：脚本面板手动粘贴

1. 下载仓库里的 `dist/小红书AI自动获客助手-obfuscated.user.js`（点开文件 → 右上角
   「Download raw file」按钮下载）
2. 点击脚本猫图标 → 打开**面板首页**（管理面板）
3. 点击左侧「+ 新建脚本」，清空编辑器中的模板代码
4. 把下载的 `.user.js` 文件用记事本打开，**全选复制**，粘贴到脚本猫编辑器中
5. 按 `Ctrl + S` 保存（或点击编辑器左上角的保存图标）

### 方式 C：脚本猫脚本站

打开脚本猫脚本站 <https://scriptcat.org/zh-CN/search?keyword=小红书AI自动获客助手>，
搜索本脚本，进入脚本详情页点击「安装」。

> ⚠️ 无论哪种方式，请确认安装的是 **`小红书AI自动获客助手-obfuscated.user.js`（发布版）**。
> 仓库中的 `src/open/` 只是界面开源模块，单独安装无法运行。

## 4. 脚本猫专属设置建议

安装完成后，建议检查以下设置（脚本猫面板 → 设置）：

| 设置项 | 位置 | 建议值 | 原因 |
| --- | --- | --- | --- |
| 脚本更新 | 脚本详情页 | 开启自动更新 | 及时获得选择器适配修复 |
| `GM_xmlhttpRequest` | 无需手动开启 | 默认放行 | AI 评论依赖此 API 直连 DeepSeek / Kimi / OpenAI / Gemini 等平台 |
| 编辑器同步 | 设置 → 同步 | 按需开启 | 保存的 API Key、文案库跟随浏览器账号同步 |
| 黑名单 | 设置 → 黑名单 | 无需配置 | 脚本自身已限定 `@match https://www.xiaohongshu.com/*` |

> 🔒 **API Key 安全说明**：脚本通过 `GM_xmlhttpRequest` 直连各 AI 平台接口，
> API Key 只保存在脚本猫的本地脚本存储中，不经过任何第三方服务器。

## 5. 验证脚本运行

1. 打开 [www.xiaohongshu.com](https://www.xiaohongshu.com) 并**登录**
2. 页面右侧应出现红色渐变标题的浮动面板「📕 小红书AI自动获客助手」
3. 首次打开面板状态栏会提示「首次使用，请先配置参数」
4. 按下面的最小配置试跑第一个任务：
   - 搜索关键词填一个具体词，例如 `美食探店`
   - 评论方式选「直评模式」，评论类型选「仅表情回复」
   - 「每个帖子评论数量」「每关键词帖子数」都填 **1**，评论间隔填 **10** 秒
   - 点「开始任务」，脚本会自动打开搜索页并逐笔记执行，面板下方显示进度

## 6. 脚本更新

- **自动更新**：如果通过 GitHub 链接安装，脚本猫会在脚本详情页显示「可更新」提示，点击即可升级
- **手动更新**：重新执行[方式 A](#方式-agithub-直装推荐)的安装步骤，新版本会覆盖旧版本；

## 7. 脚本猫常见问题 FAQ

**Q：安装脚本时提示「该脚本请求了敏感权限」？**
这是脚本请求 `GM_xmlhttpRequest`（跨域请求）和 `GM_setValue`（数据存储）的正常提示。
本脚本用前者直连 AI 平台接口生成评论，用后者保存任务进度与配置，均为必要权限。

**Q：安装后小红书页面没有出现面板？**
依次检查：① 脚本是否**启用**（脚本猫面板中开关为打开状态）；
② 当前地址是否为 `www.xiaohongshu.com`（其他域名不生效）；
③ 刷新一次页面；
④ 按 F12 打开控制台，查看是否有 `[小红书AI自动获客助手] 已加载` 日志，带日志提 Issue。

**Q：脚本猫提示「脚本与页面存在跨域请求」？**
这是 AI 评论调用 `GM_xmlhttpRequest` 访问 AI 平台（如 `api.deepseek.com`）的正常行为，
脚本已在元数据中通过 `@connect` 声明了这些域名。

**Q：可以和油猴同时安装本脚本吗？**
不建议。同一脚本装在两个管理器中会创建两个面板（ID 相同会互相拦截），只保留一处启用即可。

**Q：脚本数据存在哪里？**
脚本猫 → 面板首页 → 对应脚本 → 「数据」页签，可以查看和导出脚本存储的内容
（任务进度、配置等）。清除浏览器数据前请先导出备份。
