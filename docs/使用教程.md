## 1. 这是什么

一个运行在浏览器里的小红书网页版自动化助手，装好后小红书页面右侧会出现一个可拖动的
「📕 小红书AI自动获客助手」面板。它能按你设定的关键词列表，自动打开搜索页并逐篇笔记执行：

- **点赞**（评论前点赞，自动检测已点赞状态并跳过）
- **收藏**（评论前收藏，自动检测已收藏状态并跳过）
- **评论**：自动打开评论区，回复别人的一级评论（追评），或直接发布新评论（直评）；
  评论内容可以是表情、预设文案（随机一条）或 AI 生成的个性化回复

适合场景：账号冷启动互动、评论区维护、意向客户触达等（请务必阅读[第 11 节](#11-使用建议与风险提示)）。

| 管理器 | 下载地址 | 说明 |

### 第二步：安装本脚本

**方式 A（推荐）：GitHub 直装**

1. 打开 <https://github.com/onedarren/XHShuokezhushou/raw/main/dist/小红书AI自动获客助手-obfuscated.user.js>

## 3. 首次使用：跑通第一个任务

建议先用小参数试跑一次，确认全流程没问题再放大：

1. 打开小红书并**登录**（未登录无法点赞/评论）
2. 打开右侧面板
3. 搜索关键词填一个具体词，例如：`美食探店`
4. 评论方式选「直评模式」，评论类型选「仅表情回复」
5. 把「每个帖子评论数量」「每关键词帖子数」都改成 **1**，评论间隔改成 **10** 秒
6. 点「开始任务」——脚本会自动打开搜索页 → 进入第一篇笔记 → 点赞 → 评论 → 面板显示进度
7. 跑完 1 篇笔记后任务自动结束，确认评论确实发出去了，再按真实需求配置正式任务

## 4. 关键词搜索模式与筛选条件

脚本按关键词打开小红书搜索页（`search_result?keyword=xxx&type=51`），对搜索结果逐篇笔记执行操作。

| 设置项 | 怎么填 |
| --- | --- |
| 搜索关键词 | 多个关键词用**英文逗号**分隔，如 `注册公司,注销公司,代记账`。脚本会先把中文逗号「，」顿号「、」自动转成英文逗号 |
| 帖子类型 | 全部 / 图文 / 视频。注意：若筛选条件里选了「笔记类型」，顶部帖子类型按钮会自动跳过以避免冲突 |
| 排序依据 | 综合 / 最新 / 最多点赞 / 最多评论 / 最多收藏，留空则不筛选 |
| 笔记类型 | 视频 / 图文，留空则不筛选 |
| 发布时间 | 一天内 / 一周内 / 半年内。做时效性内容互动建议选「一周内」 |
| 搜索范围 | 已看过 / 未看过 / 已关注 |
| 位置距离 | 同城 / 附近 |
| 每关键词帖子数 | 每个关键词处理多少篇笔记后切换下一个关键词 |

筛选条件通过自动展开搜索页的「筛选」面板并点击对应选项来生效；脚本会校验点击后选项是否高亮，
并用多种点击策略兜底。执行顺序：关键词 1 的 N 篇笔记 → 关键词 2 的 N 篇笔记 → …… → 全部完成弹通知。

## 5. 操作类型：点赞 / 收藏

两个复选框（评论前点赞 / 评论前收藏）任意组合：

- **评论前点赞**：进入笔记后先点赞。脚本会先通过图标状态检测是否已点赞，已点赞自动跳过，不会取消点赞
- **评论前收藏**：先收藏，同样带状态检测；收藏会先尝试关闭收藏选集弹窗再继续

账号活跃度会随点赞/收藏自然提升，新账号建议前期多点赞收藏、少评论。

## 6. 评论功能详解

### 评论方式

| 方式 | 行为 |
| --- | --- |
| **直评模式**（direct） | 不看别人的评论，直接在帖子下发布新评论。脚本会先检测你是否已在该笔记评论过（含楼中楼回复），评论过就整篇跳过，避免刷屏 |
| **追评模式**（reply） | 打开评论区，逐条查看别人的一级评论，点「回复」按钮进行回复。适合精准触达：谁在评论区活跃就回复谁 |

### 评论类型

| 类型 | 行为 |
| --- | --- |
| **仅表情回复** | 评论内容为 `[微笑]`，最安全、最快 |
| **文本回复** | 从你填写的文案库中随机取一条发送，每行一条，例如：`讲得真好`、`学到了，感谢分享` |
| **AI回复** | 调用大模型，结合帖子描述 + 对方评论内容生成个性化回复，拟真度最高（需配置 API Key，见下一节） |

### 评论流程的小细节（自动处理，无需操心）

- 文本/AI 模式下，脚本会先点表情图标激活输入框，再把内容写入输入框并派发 input/change 事件
- **回复过滤**（仅追评模式显示）：可设置「评论内容包含」（只回复含这些词的评论）和
  「评论内容不包含」（跳过含广告、联系方式等的评论）
- **防重复**：脚本通过当前用户 ID 匹配评论作者，已回复过的评论、已评论过的笔记都会自动跳过；
  回复前会自动展开楼中楼以检查是否已回复过
- **滚动加载**：当前视图评论处理完会自动滚动加载更多；连续 3 次滚动没有新评论就切换下一篇笔记
- **发布校验**：每次发送后会检测「发布成功/失败」提示，失败自动跳下一篇

## 7. AI 评论配置

评论类型选「AI回复」后展开配置：

| 平台 | 获取 API Key | 说明 |
| --- | --- | --- |
| DeepSeek | <https://platform.deepseek.com> | 便宜，中文质量好，**推荐首选** |
| Kimi（月之暗面） | <https://platform.moonshot.cn> | 中文自然 |
| OpenAI | <https://platform.openai.com> | 需要海外支付 |
| OpenRouter | <https://openrouter.ai> | 聚合平台，一个 Key 用多家模型 |
| 小米 MiMo | 小米开放平台 | 国产新选择 |
| Gemini | <https://aistudio.google.com> | 有免费额度 |
| Ollama | 本地运行，无需 Key | 接口地址填 `http://127.0.0.1:11434/v1/chat/completions`，可自定义模型名 |

**配置步骤（以 DeepSeek 为例）**：

1. 注册并登录平台 → 创建 API Key → 复制
2. 面板：AI 模型选 `DeepSeek` → API Key 粘贴 → 保存配置
3. **AI回复提示词**决定评论的风格，默认是通用友好型，可以自定义，例如：
   ```
   你是一个做工商注册服务的小红书用户，请根据帖子内容和用户评论给出自然的回复，
   口吻像真实网友，不要太营销号，15字以内，可以适当带一个表情。
   ```
4. 点「保存配置」→ 开一次任务测试，看发出的评论效果再调整提示词

> 🔒 **API Key 安全**：Key 只保存在你自己浏览器的脚本存储里，仅用于直连对应平台，
> 不经过任何第三方服务器（本脚本无自己的后端）。

## 8. 高级设置

| 设置 | 默认 | 建议 |
| --- | --- | --- |
| 每个帖子评论数量 | 3 | 每篇笔记评论几条（追评模式下是回复几条评论；直评模式下是发几条直评） |
| 每关键词帖子数 | 2 | 关键词模式下每个关键词处理几篇笔记 |
| 评论间隔(秒) | 3 | 两次评论的最小间隔，实际会再加 0~1 秒随机值。**新账号建议 60~120 秒** |

**新账号保守参数参考**：每帖评论 1 条、间隔 90 秒、每天总评论量控制在 30 条以内、只直评不追评。

## 9. 进度面板与任务管理

任务开始后面板下方出现进度区：

- **状态**：运行中 / 已完成 / 错误信息
- **当前关键词**：正在处理的关键词
- **关键词进度 / 帖子进度 / 评论进度**：`已完成/总数`
- **进度条**：整体完成百分比

**常用操作**：

- 「停止任务」：随时可停，已保存的配置不受影响
- **换页不断**：任务跨页面执行（搜索页→笔记→下一个关键词），进度存在浏览器里，中途关掉标签页，
  重新打开小红书后面板会显示进度；卡住超过 5 分钟脚本会自动尝试恢复（重新打开当前关键词的搜索页）
- 面板**标题栏可拖动**，位置自动记住；点一下标题栏折叠成小球，再点小球展开
- 所有配置（关键词、API Key、文案库）保存后永久生效，下次打开不用重填

## 10. 常见问题 FAQ

**Q：安装后小红书页面没有出现面板？**
确认脚本已启用；刷新页面；确认地址是 `www.xiaohongshu.com`（其他域名不生效）。还没出现就按 F12
看控制台有没有 `[小红书AI自动获客助手] 已加载` 日志，带日志发 Issue。

**Q：提示「未找到评论按钮 / 评论区加载超时」？**
小红书改版导致页面结构变化。脚本对每个元素都有等待重试，偶发失败会自动跳到下一篇笔记；
如果大面积失败，请提 Issue 附上日期，等更新。

**Q：筛选条件不生效？**
小红书筛选面板为动态渲染，脚本会自动重新展开面板并多次尝试点击。若某个筛选项一直无法高亮，
可换用其他筛选维度，或提 Issue 附上操作日志。

**Q：AI 评论报错「API密钥未配置 / 请求失败 401」？**
Key 没保存成功或填错。检查：模型与 Key 是否配套（DeepSeek 的 Key 不能选在 Kimi 上）；余额是否用完；
Ollama 是否已本地启动。

**Q：任务跑到一半不动了？**
等 5 分钟看门狗会自动恢复；或者直接「停止任务」重新开始（会从未处理的进度附近继续）。

**Q：怎么让评论看起来不像机器人？**
文案库多写几条口语化短句、开启 AI 并写好提示词、加大评论间隔、开启「评论前点赞」、
优先用追评模式而不是直评。

**Q：一个账号能开几个任务？**
同时只能跑一个任务。开始按钮在任务运行中会拦截。

**Q：支持手机吗？**
不支持。本脚本运行于电脑版浏览器 + 小红书网页版。
