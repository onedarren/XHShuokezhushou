## 📕 小红书AI自动获客助手

一键开启小红书自动化获客：自动搜索笔记、点赞、收藏、评论（表情 / 文案 / AI 智能回复），
页面内浮动面板操作，任务进度自动保存、关掉页面也能续跑。

原 Chrome 扩展「小红书自动评论助手」的用户脚本移植版，**免费开源、无需授权码**，
原版的授权校验与机器码绑定已全部移除。

---

### ✨ 核心功能

**🔍 关键词自动获客**

- 填写关键词列表（英文逗号分隔），脚本自动打开小红书搜索页，逐篇笔记执行操作
- 支持多关键词轮询：关键词 1 的 N 篇笔记 → 关键词 2 的 N 篇笔记 → …… → 全部完成弹通知
- 帖子类型筛选：全部 / 图文 / 视频

**🎛 搜索筛选条件**

- 排序依据：综合 / 最新 / 最多点赞 / 最多评论 / 最多收藏
- 笔记类型：视频 / 图文
- 发布时间：一天内 / 一周内 / 半年内
- 搜索范围：已看过 / 未看过 / 已关注
- 位置距离：同城 / 附近
- 脚本自动展开筛选面板点击生效，并校验选项是否高亮，多种点击策略兜底

**❤️ 点赞与收藏**

- 评论前点赞 / 评论前收藏，可任意组合
- 自动检测已点赞/已收藏状态并跳过，绝不误取消

**💬 双评论模式**

- **直评模式**：不看别人评论，直接在帖子下发布新评论；发布前自动检测你是否已评论过该帖（含楼中楼），避免刷屏
- **追评模式**：自动打开评论区，逐条回复别人的一级评论，谁活跃回复谁，精准触达意向客户

**🤖 三种评论类型**

- **表情回复**：发送 `[微笑]`，最安全最快
- **文本回复**：自建文案库随机发送，每行一条，支持无限多条
- **AI 智能回复**：调用大模型，结合**帖子内容 + 用户评论**生成个性化回复，拟真度最高

支持的 AI 平台：DeepSeek、Kimi、OpenAI、OpenRouter、小米 MiMo、Gemini、Ollama（本地模型）。
API Key 仅保存在本地脚本存储中，通过跨域请求直连各平台官方接口，**不经过任何第三方服务器**。

**🛡 防重复与安全机制**

- 回复过滤：按「包含关键词 / 排除关键词」筛选目标评论，自动跳过广告和联系方式
- 用户 ID 识别：已回复过的评论、已评论过的笔记自动跳过
- 评论间隔：自定义秒数 + 随机抖动，模拟真人节奏
- 发布校验：每次发送后检测成功/失败提示，失败自动跳过

**📌 进度与恢复**

- 面板实时显示：当前关键词、关键词进度、帖子进度、评论进度、整体进度条
- 任务进度持久化存储，页面跳转后自动继续，中途关闭浏览器也不丢
- 卡住超过 5 分钟自动恢复，无需人工盯守

### 🚀 快速上手

1. 浏览器安装 [脚本猫](https://scriptcat.org) 并登录小红书网页版
2. 安装本脚本，打开 [www.xiaohongshu.com](https://www.xiaohongshu.com)
3. 页面右侧出现「📕 小红书AI自动获客助手」浮动面板（标题栏可拖动，可折叠成小球）
4. 首次试跑建议：填 1 个关键词，评论方式选「直评」、类型选「仅表情回复」，
   每帖评论数和每关键词帖子数都填 **1**，评论间隔填 **10** 秒，点「开始任务」
5. 观察跑完第一篇笔记效果无误后，再按需放大配置

**新账号保守建议**：每帖评论 1 条、间隔 60~120 秒、每日评论总量 ≤ 30 条。
